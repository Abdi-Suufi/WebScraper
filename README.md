# Job Search

Find UK opportunities from multiple job sources, keep your searches organised, and track every application in one quiet, focused desktop app.

## Find roles that fit

- Search jobs around Bristol or choose another UK location, radius, salary, contract type, remote preference, and posting date.
- Bring listings together from Reed, Adzuna, Arbeitnow, and DevITjobs UK. Every result links back to its original source.
- Save several searches, sort and filter results, and see newly discovered jobs.
- Track roles as Saved, Applied, Interviewing, Offer, or Rejected, with notes.
- Export your job library to CSV or JSON.
- Choose light, dark, or system appearance, and receive desktop notifications when background refresh finds matches.
- Keep the app close to hand in the Windows system tray.

## Install

Download the latest **Job Search Setup** installer from the [GitHub Releases page](https://github.com/Abdi-Suufi/WebScraper/releases), run it, and follow the installer prompts. The app is designed for Windows.

## Add free API keys

The app works without keys using the public Arbeitnow and DevITjobs UK feeds. Adding keys enables additional search sources:

1. **Reed:** Register for a free jobseeker API key on the [Reed developer page](https://www.reed.co.uk/developers/Jobseeker). Enter the key in **Settings → Job sources**.
2. **Adzuna:** Create a free account on the [Adzuna developer portal](https://developer.adzuna.com/signup) to receive an App ID and App Key. Enter both in **Settings → Job sources**.

Keys are encrypted with Windows secure storage on this device. The app tracks its own monthly API calls; provider quotas and terms can change, so check each provider’s documentation.

Jooble is listed as unavailable while its current official API request documentation cannot be verified. LinkedIn is an optional experimental build feature, off by default; it is not included in the standard release.

## Privacy and source terms

Search requests are made by the desktop app to the enabled job providers. Your API keys are not included in exports. Always review the original listing and the source’s terms before applying.

The optional LinkedIn source reads public, logged-out pages only. LinkedIn’s terms do not permit automated access; this source may stop working at any time and is intended for personal use only.
